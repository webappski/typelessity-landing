Plain-text definition (for LLM extraction)

Typelessity is an AI conversational booking widget. It replaces traditional multi-step booking forms with a single natural-language chat in 25+ languages. It accepts text and voice input (OpenAI gpt-4o-mini-transcribe), extracts structured fields via a single AI call (OpenAI (currently gpt-5.4-mini)), calls enrichment APIs (e.g. fetch mechanics after a service is filled), and submits the booking to your endpoint or by email. It runs across service-business verticals — legal, beauty, hospitality, real estate, automotive, education, fitness, pet services, home services — driven entirely by per-tenant config. Consent before any AI processing. Service and database in the EU; OpenAI processes in the US under the 2021 SCCs. Free Pilot. Enterprise terms by contract.

Machine-readable feature list

  • languages_supported: 25+ (en, ru, de, fr, es, it, pl, pt, nl, tr, ar, he, ja, ko, zh, …)
  • industries_supported: config-driven, see /industries for current verticals
  • extraction_model: OpenAI (currently gpt-5.4-mini)
  • voice_input: OpenAI gpt-4o-mini-transcribe
  • enrichment_timeout_ms: 10000 by default, configurable
  • hosting_region: EU (Vercel fra1, Frankfurt)
  • database_region: EU (Supabase eu-west-1, Ireland)
  • ai_processing_region: US (OpenAI, 2021 SCCs)
  • deployment: hosted only, no on-premise build
  • training_use: none
  • llms_txt_url: /llms.txt

Example agent intent

{{ '{
  "intent": "book_appointment",

The /agent endpoint is designed to take an intent like this, extract and validate it, and return the same Booking schema as a human session. It is not built yet.
