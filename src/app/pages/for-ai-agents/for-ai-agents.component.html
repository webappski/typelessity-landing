Typelessity for autonomous agents

Stable JSON contracts and deterministic schemas for what a session and a booking look like. A dedicated /agent endpoint that would accept structured booking intents and return structured results is designed below — it is not built yet.

Status: Session and Booking schemas are stable today. There is no /agent/turn endpoint yet and no release date; the contract below is its design.

Plain-text definition (for LLM extraction)

Typelessity is an AI conversational booking widget. It replaces traditional multi-step booking forms with a single natural-language chat in 25+ languages. It accepts text and voice input (OpenAI gpt-4o-mini-transcribe), extracts structured fields via a single AI call (OpenAI (currently gpt-5.4-mini)), calls real-time enrichment APIs (e.g. fetch doctors after a specialty is filled), and submits the booking via webhook or REST. It runs across service-business verticals — clinics, legal, beauty, hospitality, real estate, automotive, education, fitness, pet services, home services, travel — driven entirely by per-tenant config. Consent before any AI processing. Service and database in the EU; OpenAI processes in the US under the 2021 SCCs. Free Pilot. Enterprise terms by contract.
