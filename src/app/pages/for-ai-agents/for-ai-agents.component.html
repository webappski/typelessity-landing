What Typelessity is, in plain text

Typelessity is an AI conversational booking widget. It replaces traditional multi-step booking forms with a single natural-language chat. The chat window comes in 25 languages and the assistant replies in the language set for the business. It accepts text and voice input (OpenAI gpt-4o-mini-transcribe), extracts structured fields via a single AI call (OpenAI (currently gpt-5.4-mini)), calls enrichment APIs (e.g. fetch mechanics after a service is filled), and submits the booking request to your endpoint or by email. It adapts to any business that takes bookings, driven entirely by per-tenant config. Consent is asked before the chat starts. Service and database in the EU; OpenAI processes in the US under the 2021 SCCs. Free Pilot. Enterprise terms by contract.

Feature list: key and value

  • languages_supported: 25 ({{ languageCodes }})
  • reply_language: set per business, not detected
  • businesses_supported: any business that takes bookings; set up per business in config
  • extraction_model: OpenAI (currently gpt-5.4-mini)
  • voice_input: OpenAI gpt-4o-mini-transcribe
  • enrichment_timeout_ms: 10000 by default, configurable
  • hosting_region: EU (Vercel fra1, Frankfurt)
  • database_region: EU (Supabase eu-west-1, Ireland)
  • ai_processing_region: US (OpenAI, 2021 SCCs)
  • deployment: hosted only, no on-premise build
  • training_use: none
  • llms_txt_url: /llms.txt
